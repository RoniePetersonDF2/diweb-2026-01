Trabalhando com tabelas e seus atributos

Podemos usar classes, ids e estilos inline para formatar as tabelas, suas linhas e células. A classe é definida usando o atributo class, o id é definido usando o atributo id, e os estilos inline são definidos usando o atributo style.
