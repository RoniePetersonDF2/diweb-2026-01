# DIWEB-2026-01
Projetos do curso de DIWEB-I, do primeiro semestre de 2026, em HTML e CSS do curso de Técnico em Informática da Escola Técnica de Ceilândia.

## Descrição
Nesse reposítório serão disponibilizados os exercícios realizados durante o curso.
Os exercícios estarão armazenados em diretórios dividos em unidades. 
Onde cada uma delas conterá sub-diretórios representando as aulas.

## Tecnologias
Aprenderemos nesse semestre a contruir páginas em HTML e CSS. Para armazenar essas páginas utilizaermos o maior repositório de código aberto existente na WEB, o GitHub.
Para documentação usaremos preferencialmente a linguagem Markdown em arquivos README.md. Por fim, testaremos nossas páginas utilizando GitHub Pages.
